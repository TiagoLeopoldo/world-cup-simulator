RELATÓRIO TÉCNICO COMPLETO: SIMULADOR DE COPA DO MUNDO
======================================================

1. ESTRUTURA COMPLETA DO PROJETO
-------------------------------
A aplicação é um projeto React construído com Vite, estruturado da seguinte forma:

- /src/
  - App.jsx: Ponto de entrada e orquestrador principal de estado e lógica.
  - main.jsx: Inicialização do React no DOM.
  - /services/
    - api.js: Comunicação com a API para busca de times.
    - sendFinalResult.js: Comunicação com a API para envio do resultado final.
  - /utils/
    - groupDraw.js: Lógica de sorteio de grupos.
    - matches.js: Geração de partidas dentro de um grupo.
    - simulateMatch.js: Geração aleatória de gols para uma partida.
    - shuffle.js: Algoritmo de embaralhamento de arrays.
    - standings.js: Cálculo e ordenação da tabela de classificação.
    - qualification.js: Filtragem de classificados para o mata-mata.
    - roundOf16.js: Geração dos confrontos das oitavas de final.
    - knockout.js: Simulação de partidas eliminatórias (com pênaltis).
    - knockoutRounds.js: Processamento de rodadas de mata-mata.

2. FLUXO COMPLETO DE EXECUÇÃO DO APP
------------------------------------
1. Inicialização: O arquivo App.jsx é montado.
2. Efeito Inicial (useEffect):
   - Chama a função assíncrona `fetchTeams`.
   - `fetchTeams` invoca `getTeams()` (api.js).
   - O resultado é passado para `createGroups(data)`.
   - O estado `groups` é atualizado via `setGroups`.
3. Estados (useState):
   - `groups`: Armazena a estrutura completa dos 8 grupos (times, jogos e classificação).
4. Cálculos Derivados (durante o render):
   - `qualifiedTeams`: Extrai os classificados via `getQualifiedTeams(groups)`.
   - `roundOf16`: Gera as oitavas via `generateRoundOf16(groups)`.
   - `quarterFinals`: Processa as quartas via `playKnockoutRound`.
   - `semiFinals`: Processa as semis via `playKnockoutRound`.
   - `final`: Processa a final via `playKnockoutRound`.
5. Efeito de Finalização (useEffect):
   - Monitora `final.winners.length`.
   - Se houver 1 vencedor, chama `sendFinalResult(final.matches[0])`.

3. FLUXO DE DADOS REAL
----------------------
1. Entrada: JSON da API contendo array de seleções.
2. Transformação de Grupos: Os times são embaralhados e divididos em 8 sub-arrays.
3. Fase de Grupos: Para cada grupo, são geradas 6 partidas (todos contra todos).
4. Tabela: Os resultados das partidas alimentam o cálculo de pontos e saldo.
5. Classificação: Os 2 melhores de cada grupo avançam.
6. Mata-mata: 16 times -> 8 partidas (Oitavas) -> 4 partidas (Quartas) -> 2 partidas (Semi) -> 1 partida (Final).
7. Saída: Objeto formatado com os dados da final enviado via POST.

4. ESTRUTURA EXATA DOS OBJETOS EM CADA ETAPA
--------------------------------------------

A. Time Original (API GET):
   { "nome": "Chile", "token": "uuid-..." }

B. Entrada da Tabela (calculateStandings):
   Objeto acumulador que mapeia o token do time para:
   { "token": string, "team": string, "points": number, "goalsFor": number, "goalsAgainst": number, "goalDifference": number }

C. Time Classificado (getQualifiedTeams):
   { "token": string, "team": string }

D. Partida Eliminatória (Knockout Match):
   {
     "teamA": { "token", "team" },
     "teamB": { "token", "team" },
     "goalsA": number,
     "goalsB": number,
     "penaltyA": number | null,
     "penaltyB": number | null,
     "winner": { "token", "team" }
   }

E. Payload Final (POST):
   {
     "EquipeA": string (nome),
     "EquipeB": string (nome),
     "GolsEquipeA": number,
     "GolsEquipeB": number,
     "PenaltisEquipeA": number,
     "PenaltisEquipeB": number,
     "Vencedor": string (nome)
   }

5. LISTA DE FUNÇÕES UTILITÁRIAS
-------------------------------

1. shuffleArray (shuffle.js)
   - Faz: Embaralha um array aleatoriamente.
   - Input: Array.
   - Output: Novo array embaralhado.

2. simulateMatch (simulateMatch.js)
   - Faz: Gera gols aleatórios (0 a 4).
   - Input: Nenhum.
   - Output: { homeGoals, awayGoals }.

3. generateMatchesForGroup (matches.js)
   - Faz: Cria todos os confrontos de um grupo.
   - Input: Array de 4 times.
   - Output: Array de 6 partidas com placares.

4. calculateStandings (standings.js)
   - Faz: Calcula pontos e gols para cada time do grupo.
   - Input: { teams, matches }.
   - Output: Array de objetos de estatísticas por time.

5. sortStandings (standings.js)
   - Faz: Ordena a tabela por pontos e saldo.
   - Input: Array de estatísticas.
   - Output: Array ordenado.

6. getQualifiedTeams (qualification.js)
   - Faz: Seleciona os 2 primeiros de cada grupo.
   - Input: Array de grupos.
   - Output: Array de 16 objetos { token, team }.

7. simulateKnockoutMatch (knockout.js)
   - Faz: Simula partida com critério de desempate (pênaltis).
   - Input: teamA, teamB.
   - Output: Objeto completo da partida com vencedor.

8. playKnockoutRound (knockoutRounds.js)
   - Faz: Processa uma rodada inteira de mata-mata.
   - Input: Array de times.
   - Output: { matches: [], winners: [] }.

6. DEPENDÊNCIAS ENTRE ARQUIVOS
------------------------------
- App.jsx -> api.js, groupDraw.js, qualification.js, roundOf16.js, knockoutRounds.js, sendFinalResult.js.
- groupDraw.js -> shuffle.js, matches.js, standings.js.
- roundOf16.js -> knockout.js.
- knockoutRounds.js -> knockout.js.
- matches.js -> simulateMatch.js.
- knockout.js -> simulateMatch.js.

7. ESTADO GLOBAL DO SISTEMA
---------------------------
O estado reside exclusivamente no componente `App.jsx` através do hook `useState(groups)`.
- A evolução do estado ocorre uma única vez no carregamento da página após a resposta da API.
- Todas as fases subsequentes (classificação e mata-mata) são calculadas "on-the-fly" durante a renderização do App.jsx a partir do estado `groups`.

8. PONTOS DE TRANSFORMAÇÃO DE DADOS
-----------------------------------
- createGroups: Usa `slice` para dividir times em grupos e `map` para processar cada grupo.
- calculateStandings: Usa `forEach` para acumular dados e `Object.values` seguido de `map` para formatar a lista final.
- sortStandings: Usa `sort` com múltiplas condições.
- getQualifiedTeams: Usa `forEach` e `slice(0, 2)` seguido de `map` para limpar o objeto.
- playKnockoutRound: Usa laço `for` com incremento de 2 para parear times adjacentes.

9. REGRAS DE NEGÓCIO IMPLEMENTADAS
----------------------------------
- Pontuação: Vitória = 3 pts, Empate = 1 pt, Derrota = 0 pts.
- Desempate Grupo: 1º Pontos, 2º Saldo de Gols, 3º Aleatório (Math.random).
- Desempate Mata-mata: Se empate nos gols, disputa de pênaltis (simulada até haver um vencedor diferente).
- Simulador: Gols são limitados a um teto de 4 por equipe por partida.
